# Roadmap

- **Rev A board:** build and test the carrier board; results go into [Known limitations](Known-Limitations.md).
- **Real rain:** confirm the drizzle and rain detection (60 / 150 pF/min), the rain-end timer and the heater test in real rain.
- **Fog:** compare mornings with and without fog. Planned rule: after the morning heat pulse the capacitance rises again quickly while the surface is above the dew point and it is light; then the state reads fog instead of morning dew.
- **Weather add-ons:** test BME280, LTR390, anemometer, wind vane and tipping bucket (prepared in the YAML).
- **Public release:** web installer for the first flash, adoption in ESPHome, updates from GitHub releases.
- **Photos** of the finished sensor once the project leaves prototype status.
