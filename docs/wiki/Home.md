# ESPHome Capacitive Rain Sensor

A heated, sealed rain sensor for Home Assistant that tells rain from dew: RC-SPC1KA sensor element, ESP32 carrier board, ESPHome firmware. The [README](../../README.md) gives the overview; this wiki has the details.
